Step-by-Step Deployment

Follow these steps exactly. Takes about 15 minutes.

1

Get your free Groq API key

Go to console.groq.com → Sign up free → API Keys → Create key. Copy it.

2

Upload code to GitHub

Go to github.com → New repository → Upload the project zip files you downloaded.

3

Deploy on Render (free)

Go to render.com → New Web Service → Connect your GitHub repo → Set build command: npm install → Start command: node server/index.js

4

Set your environment variable

In Render dashboard → Environment → Add variable:

GROQ_API_KEY = your_key_here
5

You're live!

Render gives you a free URL like https://your-app.onrender.com — share this with your clients. That's their AI receptionist link.

Deploy one instance → set it up for a demo clinic/hospital → show the client how it handles real calls → close the sale → then deploy a fresh instance just for them with their business details. Each client gets their own private deployment on Render's free tier.
